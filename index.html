OoTR

Ocarina of Time Randomizer

Press New seed to roll a seed (or use a patch file from ootrandomizer.com) with your own Ocarina of Time 1.0 ROM. Already have a randomized .z64? Open it with Play ROM file. The tracker follows along as you play.

Everything runs in your browser. Your ROM is never uploaded.

Custom settings (JSON)

Settings in the randomizer's JSON form, on top of the preset (e.g. from the site's settings export).

or: use a patch file

On ootrandomizer.com, generate a seed and download its patch file (.zpf), then pick it here.

Spoiler log and seed page: ootrandomizer.com ↗

Seed relay

Rolling goes through a small Cloudflare Worker that holds the ootrandomizer.com API key (relay/ootr-worker.js).
